# 사주살롱

한국어·모바일 중심의 회원가입 없는 운세 서비스 MVP입니다.

## 포함 기능

- 웰컴페이지와 서비스 선택
- 기존 `ssaju` 사주 계산 엔진 기반 사주 분석
- 오늘의 운세
- 궁합 분석
- 별자리·사주 기준 띠 안내
- 입력 프로필의 브라우저 저장
- 사주·궁합 결과 공유/복사

## 실행

```bash
npm install
npm run app:dev
```

프로덕션 빌드는 `npm run build:app`으로 생성되며 결과 폴더는 `app-dist`입니다.

초기 버전은 회원가입이나 서버 저장 없이 동작합니다. 운세 결과는 자기이해를 위한 참고 콘텐츠이며 중요한 결정을 대신하지 않습니다.
